# Release Notes: v1.39.6

## Overview

Version **1.39.6** introduces the OmniGastro payment routing configuration module, enabling fine-grained control over payment processing for each tenant. This release completes the payment routing feature set and improves overall system flexibility.

## New Features

### 1. Omnigastro Payment Routing Configuration Module
- **Purpose**: Centralized management of payment routing strategies per tenant
- **Components**:
  - Backend API endpoints for configuration management
  - Frontend interface for tenant-specific routing setup
  - Database schema for storing routing rules
  - Integration with existing Odoo payment routing

### 2. Five Payment Routing Endpoints

| Endpoint | Method | Description |
|----------|--------|--------------|
| `/api/v1/omnigastro-payment-routing-config` | POST | Configure payment routing (custom or Odoo) |
| `/api/v1/omnigastro-payment-routing-config` | GET | Retrieve current payment routing configuration |
| `/api/v1/omnigastro-payment-routing-config` | PUT | Update payment routing configuration |
| `/api/v1/omnigastro-payment-routing-config` | DELETE | Remove payment routing configuration |
| `/api/v1/omnigastro-payment-routing-config/tenants/{tenantId}` | GET | Get tenant-specific routing configuration |

### 3. Tenant-Specific Routing
- Each tenant can define its own payment routing strategy
- Options include custom endpoints or Odoo-based routing
- Configurable currency, tax rules, fallback mechanisms, and rate limiting

## Improvements

- **Security**: Enhanced RBAC ensures only Super Admins can modify routing configurations
- **Monitoring**: Added metrics collection for routing performance and failure rates
- **Documentation**: Comprehensive API documentation and user guides updated
- **Testing**: All endpoints pass unit and integration tests; E2E QA confirms functionality

## Known Limitations

- Odoo 14+ required for Odoo integration (older versions may need manual configuration)
- Initial rollout targets beta tenants; production rollout planned for v1.39.7
- Some legacy tenants may experience brief downtime during configuration migration

## Migration Path

1. **Backup**: Export current payment routing settings from Odoo
2. **Deploy**: Install v1.39.6 via `./scripts/init.sh`
3. **Configure**: Navigate to `/admin/omnigastro-payment-routing-config` and set tenant-specific routes
4. **Validate**: Test all endpoints with sample transactions
5. **Rollback**: If issues occur, revert to v1.39.5 using `git checkout v1.39.5`

## Impact Assessment

- **Positive**: Greater flexibility in payment processing per tenant
- **Negative**: Requires administrative effort to configure routing per tenant
- **Risk Level**: Low – backward-compatible with existing tenants

## Support

For issues related to payment routing configuration, contact the platform support team with the affected tenant ID and error details.
