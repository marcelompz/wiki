## Conceptos Generales

### ❓ ¿Qué es OrderFlow?

**OrderFlow** es un sistema SaaS (Software as a Service) multi-tenant que te permite tener tu propia aplicación móvil y web para vender productos, sin necesidad de desarrollar una app desde cero.

**Imaginá esto:**
- 🏢 OrderFlow es como un **centro comercial digital premium**
- 🏪 Tu negocio tiene **su propio local** (tu API Key)
- 🎨 Tu **branding y colores** son tu vidriera
- 🔒 Tus **datos y clientes** están en tu espacio privado
- ⚡ Toda la **infraestructura ya está instalada** (solo entrás y usás)

---

### ❓ ¿Para qué tipos de negocios es OrderFlow?

OrderFlow es **agnóstico al rubro**, funciona para:

| Rubro | Caso de Uso | Ejemplo |
|-------|-------------|---------|
| 🌿 **Spa/Wellness** | Venta de productos + reserva de turnos | SPA Wellness |
| 🚗 **Automotriz** | Repuestos y accesorios | Auto Repuestos |
| 🏪 **Retail** | Tienda online multi-categoría | Tiendas de barrio |
| 💊 **Farmacia** | Productos + delivery | Farmacias locales |
| 🍕 **Alimentos** | Pedidos + pickup/delivery | Restaurantes |
| 📦 **Cualquier negocio** | Sistema configurable | Tu negocio |

## API Key y Multi-Tenant

### ❓ ¿Qué es una API Key?

**No es solo un código técnico.** Tu API Key es:

| Técnicamente | Comercialmente |
|--------------|----------------|
| Credencial de autenticación | **La llave de tu local digital** |
| Identificador único | **Tu identidad en la plataforma** |
| Token de acceso | **Tu derecho de uso del sistema** |

**Analogía del Centro Comercial:**
> Tu API Key es como tener tu propio local en un centro comercial premium. El edificio (OrderFlow) ya está construido, pero tu local es 100% tuyo: tu decoración, tus productos, tus clientes, tu caja registradora.

---

### ❓ ¿Qué significa "multi-tenant"?

**Multi-tenant** significa que múltiples negocios comparten la misma infraestructura, pero cada uno tiene sus datos completamente aislados.

**Beneficios para vos:**

| Ventaja | Explicación | Ahorro |
|---------|-------------|--------|
| 💰 **Costos compartidos** | La infraestructura se divide entre todos los tenants | 90% menos que desarrollar solo |
| 🚀 **Inicio inmediato** | No hay que construir nada, solo configurás tu espacio | Empezás hoy mismo |
| 🔒 **Datos privados** | Cada tenant tiene aislamiento total de datos | Nadie ve lo de nadie |
| ⚡ **Actualizaciones automáticas** | Mejoras para todos sin costo adicional | Sin pagar updates |

**Tus datos están 100% aislados:**
- Otros negocios NO ven tus productos
- Otros negocios NO ven tus clientes
- Otros negocios NO ven tus ventas
- Vos NO ves los datos de otros (a menos que quieras)

---

### ❓ ¿Puedo tener más de una API Key?

**Sí**, esto es útil si tenés:

- 🏪 **Múltiples sucursales** (cada local con su configuración)
-  **Múltiples marcas** (diferentes brands, misma empresa)
- 👥 **Múltiples equipos** (uno para ventas, otro para admin)

**Disponible en:** Plan Enterprise (USD 199/mes)

## Seguridad y Datos

### ❓ ¿Mis datos están seguros?

**Sí, más seguros que en tu computadora.**

**Medidas de seguridad:**

| Capa | Protección |
|------|------------|
| 🔒 **En tránsito** | SSL/TLS (como los bancos) |
| 🔐 **En reposo** | Encriptación AES-256 |
| 🛡️ **Acceso** | API Key única por tenant |
| 📊 **Aislamiento** | Cada tenant en su "caja fuerte" |
| 💾 **Backups** | Diarios por 30 días |
| 🏢 **Servidores** | Data centers Tier III |

**Comparación:**
- 📁 **Tu computadora:** Vulnerable a virus, robo, falla de disco
- ☁️ **OrderFlow:** Protección de nivel bancario

---

### ❓ ¿Quién puede ver mis datos?

**Solo personas autorizadas:**

| Persona | ¿Ve qué? |
|---------|----------|
| 👤 **Vos (dueño)** | Todo (productos, clientes, ventas) |
| 👥 **Tu equipo** | Solo lo que les permitas |
| 🤖 **OrderFlow (sistema)** | Solo para funcionar (backups, updates) |
| 👨‍💼 **Otros tenants** | NADA (aislamiento total) |
| 🌍 **Público general** | Solo tu catálogo (lo que querés mostrar) |

## Migración y Cancelación

### ❓ ¿Cómo me mudo desde mi sistema actual?

**Proceso en 4 pasos:**

1. **📋 Exportá** tus datos actuales (productos, clientes)
2. **📤 Importá** a OrderFlow (te ayudamos)
3. **🎨 Configurá** tu branding (colores, logo)
4. **🚀 Lanzá** tu app (en 24-48 horas estás operativo)

**Ofrecemos:**
- ✅ Migración asistida gratuita (Plan Professional+)
- ✅ Importación masiva desde Excel/CSV
- ✅ Integración con sistemas populares

---

### ❓ ¿Qué pasa si quiero cancelar?

**Podés cancelar cuando quieras.** Sin preguntas incómodas.

**Proceso:**

1. Avisás con 30 días de anticipación
2. Exportás tus datos (te ayudamos)
3. Tu API Key se desactiva
4. No hay más cargos

**Política de reembolso:**
- 📅 Dentro de los primeros 30 días: Reembolso completo
- 📅 Después de 30 días: Proporcion al tiempo no usado

---

### ❓ ¿Mis datos se borran si cancelo?

**No inmediatamente.**

**Cronograma:**
- 📅 **Día 1:** Cancelación solicitada
- 📅 **Día 1-30:** Acceso de solo lectura (podés exportar)
- 📅 **Día 31-60:** Backup en frío (recuperable con costo)
- 📅 **Día 61+:** Eliminación permanente (GDPR compliant)

**Te avisamos** por email antes de cada etapa.
